# 課後活動場地借用申請表產生器

單一檔案網頁(`index.html`),填資料後產生 A4 PDF。
- 3 筆以內:1 頁 A4,上下兩聯
- 4~12 筆:2 頁,每聯各一頁(只顯示實際填寫的時段)

填完按「下載 PDF」,檔案會下載到自己的裝置,並自動同步存進管理員的 Google 雲端。

## 管理員:更換自動上傳的接收端

1. 開 <https://script.google.com> → 新增專案 → 把 `apps-script/Code.gs` 全部貼上。
2. 把 `TOKEN` 改成自己的通關碼。
3. 「部署」→「新增部署」→ 類型選「網頁應用程式」
   - 執行身分:**我**
   - 誰可以存取:**所有人**
4. 複製部署後的網址,編輯 `index.html`,填入這一行:
   ```js
   const UPLOAD_URL="https://script.google.com/macros/s/.../exec", UPLOAD_TOKEN="你的通關碼";
   ```

## 注意
- 通關碼會寫在網頁原始碼裡,只能擋一般人。知道網址的人仍可往雲端丟 PDF(接收端只收 `%PDF` 檔、單檔上限約 6MB)。
- PDF 內含姓名與手機,雲端資料夾請不要設成公開。
- **這個儲存庫是公開的,請不要把真實的姓名、電話放進程式碼或紀錄裡再提交。**
