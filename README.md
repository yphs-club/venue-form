# 課後活動場地借用申請表產生器

單一檔案網頁,填資料後產生 A4 PDF。
- `index.html`:場地借用申請表。3 筆以內 1 頁 A4(上下兩聯);4~12 筆 2 頁。
- `consent.html`:家長同意書(平時課後練習)。自動帶入借用單的社團、場地、人數與時段;每份只含一個月份。

填完按「下載 PDF」,檔案會下載到自己的裝置,並自動同步存進管理員的 Google 雲端,先依社團、再依表單種類分資料夾:

```
社團申請表單/
  儀隊/
    場地借用單/…pdf
    家長同意書/…pdf
  熱音社/
    場地借用單/…pdf
  未填社團/…    (網頁沒填社團名稱時)
  其他/…pdf        (檔名不是借用單或同意書時)
```

## 管理員:設定自動上傳的接收端

1. 開 <https://script.google.com> → 新增專案 → 把 `apps-script/Code.gs` 全部貼上。
2. 把 `TOKEN` 改成自己的通關碼。
3. 「部署」→「新增部署」→ 類型選「網頁應用程式」
   - 執行身分:**我**
   - 誰可以存取:**所有人**
   - 第一次會要求授權雲端硬碟權限,同意即可。
4. 複製部署後的網址,填進 `index.html` 和 `consent.html` 裡這一行:
   ```js
   const UPLOAD_URL="https://script.google.com/macros/s/.../exec", UPLOAD_TOKEN="你的通關碼";
   ```
5. 之後更新接收端程式:部署 → 管理部署作業 → 編輯(鉛筆)→ 版本選「新版本」→ 部署。網址不會變。

## 注意
- 通關碼會寫在網頁原始碼裡,只能擋一般人。知道網址的人仍可往雲端丟 PDF(接收端只收 `%PDF` 檔、單檔上限約 6MB)。
- PDF 內含姓名與手機,雲端資料夾請不要設成公開。
- 不填 `UPLOAD_URL` 就不會上傳,維持原本只下載。
- **這個儲存庫是公開的,請不要把真實的姓名、電話放進程式碼或紀錄裡再提交。**
